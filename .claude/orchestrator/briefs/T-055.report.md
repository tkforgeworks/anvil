## 2 Changes
- `scripts/release/build-linux.sh` (new, +x):
  - Reads the version from pubspec (`X.Y.Z[-rc.N]+BUILD` → file version `X.Y.Z[-rc.N]`, package
    version `X.Y.Z[~rc.N]`) and validates it.
  - `--skip-flutter-build`, and `-h` prints the header.
  - Fetches nfpm 2.48.0, appimagetool 1.9.1 and type2-runtime 20251108 (pinned, sha256 checked
    before use, cached in `build/linux-packaging/tools/`).
  - Computes the glibc floor from `readelf --dyn-syms` over the binary and `lib/*.so`.
  - Removes old `release/anvil-*-linux-*`, runs nfpm for deb and rpm, then assembles the AppDir
    in `build/linux-packaging/Anvil.AppDir` and runs appimagetool (`APPIMAGE_EXTRACT_AND_RUN=1`,
    `--no-appstream`, `--runtime-file`).
- `linux/packaging/nfpm.yaml`:
  - Metadata as briefed. `version_schema: none`, `release: "1"`.
  - Contents:
    - the bundle as `type: tree` → `/opt/Anvil` (directories owned)
    - symlink `/usr/bin/anvil` → `/opt/Anvil/anvil`
    - the desktop file
    - `resources/icon.png` → `/usr/share/icons/hicolor/512x512/apps/com.tkforgeworks.anvil.png`
    - LICENSE and NOTICE → `/usr/share/doc/anvil/`
  - deb Depends lists package names with t64 alternatives. rpm Requires lists sonames
    (`libgtk-3.so.0()(64bit)` …), so rpm resolves them on any distro.
  - Both declare `libc (>= ${ANVIL_GLIBC_MIN})`, plus EGL and GLESv2 (see Deviations).
  - `postinstall.sh` runs as the deb postinst and as the rpm `%posttrans`.
- `linux/packaging/postinstall.sh` (+x):
  - Removes any leftover `anvil` alternatives registration.
  - Recreates `/usr/bin/anvil` if it does not point at `/opt/Anvil/anvil`.
  - Deletes empty directories only, under `/opt/Anvil/locales` and `/opt/Anvil/resources`.
- `linux/packaging/AppRun` (+x): runs `$APPDIR/opt/anvil/anvil "$@"`.
- `linux/packaging/com.tkforgeworks.anvil.desktop`: `Exec=anvil %U`, `Icon=com.tkforgeworks.anvil`,
  `StartupWMClass=com.tkforgeworks.anvil`, `Categories=Utility;`, plus Name, GenericName, Comment
  and Terminal=false.
- `.gitignore` unchanged: `build/` and `/release/` already cover the outputs.

## 4 Deviations
- **EGL and GLESv2 are declared** (`libegl1`, `libgles2` / `libEGL.so.1()(64bit)`,
  `libGLESv2.so.2()(64bit)`), although they appear in no NEEDED list. libepoxy loads them with
  dlopen. Without them, a bare Debian 13 with GTK aborts with `Couldn't open libEGL.so.1` and then
  `Couldn't open libGLESv2.so.2` (exit 134). Rejected alternative: GTK only, which works on Fedora
  only because gtk3 happens to pull in Mesa there.
- **rpm requires are sonames, not package names.** That is how rpm itself writes them. Rejected:
  Fedora package names, which do not match openSUSE.
- **The glibc floor is computed, not hard-coded 2.35.** It is the newest `GLIBC_x.y` symbol the
  bundle uses, and it is **2.34** even when built on 22.04. 2.35 is the build host's glibc, not
  the floor. The brief's 2.35 is a difference, but harmless.
- **One icon size (512x512)**, the same as 0.1.6. Resizing needs ImageMagick or PIL, which the
  runner contract does not promise. Rejected: committing resized PNGs of an all-rights-reserved
  asset without being asked.
- **Leftover-directory cleanup in `postinstall.sh`.** The 0.1.6 rpm listed files but not
  directories, so after the upgrade empty `/opt/Anvil/locales` and `/opt/Anvil/resources/...` trees
  stayed behind, and `/opt/Anvil` itself survived a later uninstall. The script removes only empty
  directories under those two 0.1.x-only paths. Rejected: `rm -rf`.
- **The bundle sits at `$APPDIR/opt/anvil/`** in the AppImage. Rejected: putting the bundle at the
  AppDir root next to `AppRun`.
- **Added `/usr/share/doc/anvil/{LICENSE,NOTICE}`** to the deb and rpm, plus `GenericName` in the
  desktop file. Neither was asked for. Both are cheap to drop.
