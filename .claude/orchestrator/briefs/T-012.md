## Expected outcome
- `T saveTransaction<T>(String description, T Function(SaveScope tx) body)` on
  `ProjectDatabase`, synchronous like `read` (the `Future`s live on the repository interfaces):
  `BEGIN IMMEDIATE`; run `body`; `INSERT INTO save_history (saved_at, description,
  is_auto_save) VALUES (datetime('now'), ?, 0)`; trim to 50 exactly as 0.1.6 does (count, then
  delete the oldest `count - 50` by `saved_at ASC`); `COMMIT`; on any throw `ROLLBACK` when
  `!autocommit` and rethrow. `SqliteException` thrown by the body is mapped: a `UNIQUE`
  constraint failure whose message names `export_key` becomes `DuplicateExportKey(exportKey?)`
  (extract the key if the message carries it, else null); any other `SqliteException` becomes
  `SaveFailed(message, cause)`. Exceptions that are already core types pass through unchanged.
  Nested `saveTransaction` or `saveTransaction` inside `read` throws `StateError`.
- `SaveScope` (like `ReadScope`, valid only inside the body): `ResultSet select(sql, [params])`,
  `void execute(sql, [params])`, `int get changes` (rows changed by the last statement, from the
  handle) so a domain save can require exactly one updated row, and `String get nowSql` is NOT
  wanted; domain code writes `datetime('now')` itself.
- `errors.dart` gains: `RecordNotFound(domain, id)`, `SaveBlocked(List<String> blockers)`,
  `DuplicateExportKey(String? exportKey)`, `MetaInUse(String kind, Map<String, int> counts)`,
  `SaveFailed(String message, Object cause)`; all `implements Exception`, `final`, useful
  `toString()`. (`ProjectLocked` stays in `project_errors.dart`; do not move it.)
- `save_history.dart`: `SaveHistoryEntry(id, savedAt, description, isAutoSave)` with `savedAt`
  converted as 0.1.6 does (`'2026-11-01 14:00:00'` → `'2026-11-01T14:00:00Z'`), and
  `List<SaveHistoryEntry> readRecentSaves(ProjectDatabase db, {int limit = 50})` ordered
  `saved_at DESC` using `db.read`.
- `save_descriptions.dart`: pure functions producing the 0.1.6 strings: `recordChanged(domain,
  name)` → `Fireball - Ability changed`, `recordCreated`, `recordDeleted`, `recordRestored`,
  `recordDuplicated`, `recordHardDeleted` (`permanently deleted`), `bulkChanged(domain, count,
  action)` → `3 items deleted` (plural label from `DOMAIN_LABELS`; `NPC`/`NPCs` and
