## Decisions already taken (do not reopen)
- **Router.** `lib/app/shell/app_router.dart` builds one `GoRouter` (`routerProvider`) with
  `initialLocation: '/'`, a top-level `/welcome` route rendering `WelcomePage` outside the shell,
  and a `ShellRoute` whose builder is `AppShell(child)` holding the routes `/` (dashboard),
  `/classes`, `/classes/:id`, `/abilities`, `/abilities/:id`, `/items`, `/items/:id`, `/recipes`,
  `/recipes/:id`, `/npcs`, `/npcs/:id`, `/loot-tables`, `/loot-tables/:id`, `/validation`,
  `/recycle-bin`, `/export` (the 0.1.6 paths). A `redirect` sends every location to `/welcome`
  while `projectSessionProvider` is null and `/welcome` to `/` once a session exists;
  `refreshListenable` is driven by the session provider (a small `ChangeNotifier` the provider
  scope keeps in sync is fine; `ref.listen` in the router provider). `AnvilApp` becomes
  `MaterialApp.router`; `AnvilHome` and `ProjectOpenPlaceholder` are deleted.
- **Placeholders.** Each page route renders `PagePlaceholder(title)` (a centred title and the
  line "Coming in <ticket>": Dashboard and Validation ANVL-198, Abilities ANVL-191, Items
  ANVL-192, Recipes ANVL-193, Loot Tables ANVL-194, Classes ANVL-195, NPCs ANVL-197, Recycle Bin
  ANVL-199, Export ANVL-200; use these keys as given, they were checked in Jira) and each editor route renders `EditorPlaceholder(domain, id)`.
  Keep them in `lib/app/shell/placeholders.dart` so the later tickets replace one file.
- **Editing mode.** `lib/app/shell/open_editor.dart`: `void openEditor(BuildContext context,
  WidgetRef ref, ShellDomain domain, String id)` reads `ref.read(appSettingsProvider).editingMode`
  at call time; `fullPage` → `context.go('/<domain path>/$id')`; `modal` → `showDialog` with
  `EditorDialog(title, child)` (the port of `EditorModal`: `Dialog` sized to 85 % of the window
  height and `AnvilLayout.editorDialogMaxWidth`, a new constant of 1200 (MUI's `lg` breakpoint)
  you add to `lib/app/theme/anvil_metrics.dart`, the one theme-file edit allowed, title row with a close `IconButton`, the editor
  widget inside a scroll view). The editor widget comes from one registry
  `editorBuilders: Map<ShellDomain, Widget Function(String id)>` in `placeholders.dart` (all
  `EditorPlaceholder` for now) so the route and the dialog never duplicate editor widgets.
  `ShellDomain` is an enum in `lib/app/shell/shell_domain.dart` with the six domains, their
  labels, route paths and `SaveDomain` mapping (verify `SaveDomain` in
  `packages/anvil_core/lib/src/db/save_descriptions.dart`).
- **Providers** in `lib/app/shell/shell_providers.dart`: `requireSessionProvider`
  (`ProjectSession`, throws `StateError` when null; only widgets inside the shell read it); one
  `Provider` per repository interface over the session's field (`classRepositoryProvider` …
  `lifecycleRepositoryProvider`, `templateRepositoryProvider`, `saveHistoryRepositoryProvider`,
  `metaRepositoryProvider`, `customFieldRepositoryProvider`); `writeEpochProvider`
  (`Notifier<int>` with `bump()`; every write in the app will call it, so counts and badges
  refresh; document that contract); `recordCountsProvider` (`FutureProvider<RecordCounts>` over the
  six `countActive()` calls, watching `writeEpochProvider`); `trashCountProvider`
  (`FutureProvider<int>` over `countDeleted()`, summed if it is per domain, watching the epoch);
  `validationIssuesProvider` (`AsyncNotifier<List<ValidationIssue>>` that runs
  `ValidationService.runProject()` on build and on every epoch bump, debounced 500 ms, and
  exposes `refresh()`; the Validation page ANVL-199 reads the same list); `sidebarCollapsedProvider`
  (`Notifier<bool>`, default false, session only, not persisted). Everything watches
  `projectSessionProvider` directly or through `requireSessionProvider`, so replacing the session
  rebuilds all of it (acceptance criterion "opening another project replaces the session and
  disposes editor state").
- **Sidebar** `lib/app/shell/sidebar.dart`: a `Column` of its own, not `NavigationRail` (the
  rail cannot show counts and badges in the expanded form), `AnimatedContainer` width `AnvilLayout.sidebarWidth` (220) / `AnvilLayout.sidebarCollapsedWidth` (56),
  both already defined, over 200 ms, entries as in `Sidebar.tsx`: Dashboard, divider, the six domains with their active
