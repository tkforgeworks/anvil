## Decisions already taken (do not reopen)
- New directory `lib/app/editor/widgets/`: `edit_header.dart` (`EditHeader<T>`: back action, display
  name, read-only export key in `ForgeType.code`, undo/redo buttons enabled from `canUndo`/`canRedo`,
  Save button enabled from `canSave`, a save-error line from `saveError`; takes the editor provider
  and callbacks, watches the provider itself), `save_bar.dart` (`SaveBar<T>`: shown only while dirty,
  Discard → `discard()`, Save → `save()`, Save disabled while blocked or saving, the first blocker
  message shown beside the buttons as 0.1.6's SaveBar showed the disabled reason), `dirty_dot.dart`
  (`DirtyDot` 6 px primary dot; `TabDirtyTracking` = a pure function
  `Set<String> dirtyTabs<T>(T baseline, T draft, Map<String, bool Function(T a, T b)> tabFields)` the
  editors call to decide which tabs show the dot; no hook), `draft_text_field.dart` (the spike's
  `DraftTextField` ported: a `TextField` whose text follows `value` without moving the caret when the
  draft changes under it from undo/redo, and whose `onChanged` calls back; `blockerMessage` /
  `issueMessage` optional props render as the field's `errorText`), `validation_banner.dart`
  (`ValidationBanner(issues)`: hidden when empty, otherwise a `ForgeErrorCard`-style block listing
  errors then warnings with the 0.1.6 severity labels; `fieldIssueText(issues, field)` helper for
  per-field indicators), `record_validation.dart` (`recordValidationProvider`: a family keyed by
  `(ValidationDomain, recordId)` that runs the single-record pass after a save and is refreshed by
  the editor; decide the mechanism from what the core exposes and document it; it must not open a
  second write connection and must run off the UI isolate if the core offers that).
- `lib/app/editor/exit_prompt.dart`: `Future<bool> confirmLeaveAll(BuildContext context, WidgetRef ref)`
  reads `dirtyEditorsProvider`; with no dirty editors returns true at once; otherwise shows a dialog
  listing each dirty editor (`<displayName> (<domain singular>)`) with Save all / Discard all /
  Cancel. Save all runs `saveAll()`; if it returns false the dialog stays with the failing editor's
  `saveError` shown and the user remains in the app (returns false on Cancel). Discard all calls
  `discard()` on every dirty controller through the registry (add a `discard` callback to
  `DirtyEditor` if the registry lacks one; that edit to `dirty_editors.dart` is allowed) and returns
  true. The dialog is a separate route so it falls outside any editor's shortcut layer (§8.7).
- `AppExitHandler.onExitRequested` consults `confirmLeaveAll` through the router's root navigator

  returns false and logs the shutdown line only on exit. This is the one edit to `app_router.dart`.
