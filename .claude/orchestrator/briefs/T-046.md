## Decisions already taken (do not reopen)
- `RecordTable<R>` gains an optional `contextMenuFor: List<RecordRowAction>? Function(R row)?`.
  When it returns a non-empty list for a row, every data cell of that row (not the checkbox cell)
  is wrapped in a `GestureDetector(behavior: HitTestBehavior.translucent, onSecondaryTapUp: ...)`
  that opens the table's single context menu at the pointer. One `MenuAnchor` wraps the whole
  table (a private `StatefulWidget` `_ContextMenuRegion` holding the `MenuController` and the
  target row, so `RecordTable` itself stays stateless); opening for another row closes the first
  by reusing the controller. Menu rows are `MenuItemButton`s keyed `RecordTable.contextMenuKey(label,
  id)` (`ValueKey('record-table-menu-<label>-<id>')`), the destructive one styled like the app
  menu's danger rows, each calling the action's `onPressed` and closing the menu. Width: let the
  menu size to its content (0.1.6's 240 px is not ported). No `KbdPill`: rows have no shortcuts.
- `RecordListPage` passes `contextMenuFor` only in `ListViewMode.active`: Edit (`_open`),
  Duplicate (`_duplicate`), Export (see EXPORT HANDOFF), Move to Recycle Bin (`_softDelete`, the
  same instant soft delete with the Undo snackbar as the Delete icon; no confirmation, since
  0.2.0's lists confirm nothing that can be undone). The row's icon buttons are unchanged. Archived
  mode passes null, so the gesture detector is not even mounted there.
- The recycle bin's `TrashGroupTable` (which wraps `RecordTable`) passes nothing, so trash rows
  have no menu, as the ticket asks.
- Tests: `test/lists/record_table_context_menu_test.dart` over the existing in-memory fake adapter
  from `test/lists/` (look at how `record_list_page_test.dart` builds its page): right-click
  (`tester.tapAt(pos, buttons: kSecondaryButton)` after `ensureVisible`) opens the four rows;
  Edit calls `onOpen`; Duplicate and Move to Recycle Bin go through the adapter (Undo snackbar shown
  for the delete); Export performs the handoff (see above); Esc closes; right-clicking a second row
  closes the first and shows the second's rows; the archived view opens nothing on right-click;
  Arrow Down + Enter activates the second row.
