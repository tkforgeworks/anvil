## Decisions already taken (do not reopen)
- Pure math in `lib/app/domains/classes/classes_growth_fill.dart`: `sealed class FillShape` with
  `StepFill(increment)`, `MultiplyFill(factor, cap)`, `ApproachFill(limit, rate)`,
  `ExpressionFill(formula)`; `FillResult = ({Map<int, double> values, String? error})`;
  `computeFormulaFill({required FillShape shape, required int fromLevel, required int toLevel,
  required double start, required int maxLevel})` walking `from..to` (limited to 1..maxLevel, empty
  with an error when `from > to`) carrying `prev`, rounding each value with the same 3-decimal rule
  as `interpolateLevels`, evaluating Expression through `evaluateFormula(formula, {'level', 'max_level',
  'prev'})` and stopping at the first error (its message as `error`, no values). Multiply clamps
  with `min(prev * factor, cap)`; Approach is `prev + (limit - prev) * rate`, which never crosses
  the limit for `rate` in (0, 1].
- Controller: `formulaFill(statId, Map<int, double> values)` on `ClassEditorController`, a thin
  wrapper over `_editManualColumn` so the whole fill is one undo step; the page computes the
  values (the controller stays free of UI state).
- UI: `_FormulaFillHelper` in `classes_stat_growth_tab.dart` after `_InterpolateHelper`, same
  `Wrap` row style: `_helperLabel(context, 'Formula fill:')`, stat `DraftPicker` (manual stats
  only), `From lvl` / `To lvl` `IntDraftField`s (defaults 1 and max level), `Start` number field
  (blank = seed from the grid cell at `from`, helper text `blank = current value`), a `Shape`
  `DraftPicker` with `Step` / `Multiply with cap` / `Approach limit` / `Expression`, then the
  shape's inputs (`+ per level`; `× factor` and `Cap`; `Limit` and `Rate` 0–1; a formula field with
  hint `e.g. prev * 1.1 + level`), a `Preview` strip showing the computed values as `L1 10 · L2 12 ·
  …` (ellipsis after 12 entries with `… Ln value`) or the error in the error colour, recomputed on
  every input change, and `Apply` enabled only when a stat is chosen and the preview has values.
  Keys: `class-growth-ffill-stat`, `-from`, `-to`, `-start`, `-shape`, `-increment`, `-factor`,
  `-cap`, `-limit`, `-rate`, `-expression`, `-preview`, `-apply`, exposed as `static const`s on
  `ClassStatGrowthTab` like the existing helper keys.
