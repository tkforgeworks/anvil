  the provider (tests override it). Save As is then enabled whenever a project is open.
- Backup: an outlined `Backup` button in the hero next to Quick add. It suggests

  folder structure, else the file's folder). On success show a snackbar `Backup saved to <path>`;
  on failure the lifecycle's message; cancel does nothing. Backup does not switch the session.
