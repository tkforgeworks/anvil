  texts `All changes saved`, `Unsaved Changes` (with the count in a tooltip, `3 records with unsaved
  changes`), `Saving...`, `Save Error` with the message in a tooltip; a small leading dot or icon

  keeping the key on the new widget. That slot line and its import are your only edits in
  `app_shell.dart`, plus one `ref.watch(checkpointSchedulerProvider)` line so the scheduler lives
  while the shell is mounted.
- `lib/app/project/checkpoint_scheduler.dart`: `checkpointSchedulerProvider`, a `Notifier` that listens
  to `writeEpochProvider` and, 5 seconds after the last bump with no further bump, runs a `PASSIVE`
  checkpoint on the open session's database (`quietCheckpointDelay = Duration(seconds: 5)`). A bump
  restarts the timer; a cleared session cancels it; a failing checkpoint is logged as a warning and
  never thrown. Use `clockProvider` or an injectable timer factory so tests do not wait. If
  `ProjectSession.database` is `@internal`, add `void checkpoint(CheckpointMode mode)` to
  `ProjectSession` in the core (the one core edit allowed) and call that.
- `AppExitHandler._onExitRequested`: after `confirmLeaveAll` answers true and a session is open, await
  `ref.read(projectLifecycleProvider.notifier).closeProject()` (which checkpoints `TRUNCATE`, closes
  the handle and releases the lock) before logging the shutdown line and returning `exit`. A failed
  close is logged and does not block exit.
- Core test: in `packages/anvil_core/test/project/project_service_test.dart` add a case that writes a
  row through a `saveTransaction` (so pages sit in the `-wal` file), then `backup` and `saveAs`, and
  opens each copy read-only to find the row. Skip whichever already exists; report.
- Nothing is removed from `AppSettings`; the ticket's "removed from app settings" is satisfied by the
  keys being unused and unshown (verify `grep -rn autoSave lib/` shows no UI use).
