  Use enums for `theme` and `editingMode` with the exact JSON strings above. `normalize(Map json)`
  reproduces `normalizeSettings`: unknown or wrong-typed values fall back to the default, hex
  colours validated with the same regex `^#[0-9a-fA-F]{6}([0-9a-fA-F]{2})?$`, invalid entries
  dropped the way Electron drops them (check whether a bad colour drops the key or the whole
  object, and match).
- `AppSettingsStore({required String filePath})`: `AppSettings read()` (missing or unparsable
  file → defaults, never throws), `AppSettings write(Map<String, Object?> partial)` or
  `update(AppSettings Function(AppSettings))` that merges over the current file then normalizes
  then writes, as Electron does; the written JSON must load unchanged by 0.1.6's reader (same
  keys; match Electron's indentation, check `JSON.stringify` arguments). Test: a file with the
  eight keys as 0.1.6 writes them round-trips byte-identically through read → write.
- Logger: `AppLogger({required String directory, required LogLevel minimumLevel})` (the app passes
  `kReleaseMode ? info : debug`); `error(String message, [Object? error, StackTrace? st])`,
  `warn`, `info`, `debug`; line format `<ISO timestamp> [TAG] message` with tags `ERROR`,
  `WARN `, `INFO `, `DEBUG` (note the padding spaces) and the timestamp in JS
  `toISOString` form (`YYYY-MM-DDTHH:mm:ss.sssZ`, UTC, milliseconds); error lines append the
  error and stack as Electron does (check the exact separator); synchronous appends
  (`writeAsStringSync(mode: append)`); the file is `<directory>/anvil.log`; directory created on
  first write; rotation before an append when the file size ≥ 5 MB: `.3` deleted, `.2`→`.3`,
  `.1`→`.2`, `anvil.log`→`.1` (match `log-rotation.ts` order exactly); the logger never throws
  (swallow I/O errors). Also a `Logger` abstraction is NOT wanted; one concrete class is enough.
  `anonymizePath(String)` returns the last two path segments as Electron does (check the
  separator handling for Windows paths and port it).
- Tests: normalization of every key (valid, invalid type, missing, out-of-range interval, bad hex,
  unknown theme string → default); store round-trip of a 0.1.6-shaped file (hand-written in the
