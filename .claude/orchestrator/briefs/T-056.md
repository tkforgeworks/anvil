## Goal
`scripts/install/install-anvil.sh` (Linux) and `scripts/install/install-anvil.ps1` (Windows) resolve
a GitHub release of `tkforgeworks/anvil`, download the right asset for the host, verify it, and
install or upgrade Anvil in place. The full acceptance criteria are the Jira description of ANVL-143,
rewritten 2026-11-03; they are reproduced under "Acceptance criteria" below and are the spec.

## Why
Testers and Tim install every RC by hand from the Releases page. These scripts make it one command,
re-runnable to update. The packaging they install is brand new (ANVL-167 Windows, ANVL-168 Linux,
both merged into `v0.2.0/main`), and **no 0.2.0 release has been published yet**: the only releases
on GitHub are 0.1.x, whose assets use electron-builder names the scripts must reject. So the scripts
are tested against a local fake release (see Done-check).

## Decisions already taken
- **API override for tests:** env `ANVIL_RELEASES_API` (default
  `https://api.github.com/repos/tkforgeworks/anvil`), same name in both scripts, documented in help
  as a testing aid. Downloads use each asset's `browser_download_url` from the JSON as given, so a
  fake release served locally can point at local files.
- **JSON without jq** on Linux: use `python3` if present, else fail with a clear message naming it.
  (Every target distro has python3 in its base desktop install; containers may need it installed.)
  PowerShell uses `Invoke-RestMethod`.
- **Version compare:** deb hosts via `dpkg --compare-versions`; rpm hosts via
  `rpm --eval '%{lua: print(rpm.vercmp("a","b"))}'` (or `rpmdev-vercmp` if present); AppImage path
  via a small pure comparison of `X.Y.Z[-rc.N]` (stable > any rc of the same X.Y.Z). PowerShell: a
  pure function over `X.Y.Z[-rc.N]` with the same rule. Installed versions from 0.1.x (e.g. `0.1.6`)
  compare as older.
- **Downgrades:** default and `--stable` never downgrade (report "installed X is newer than Y" and
  exit 0); an explicit tag installs even if older (`apt-get install -y --allow-downgrades`,
  `dnf install -y` handles a local older rpm via `dnf downgrade`-style; verify and use what works).
- **AppImage install:** `~/.local/bin/anvil`, desktop file
  `~/.local/share/applications/com.tkforgeworks.anvil.desktop` (copied from the AppImage's own
  desktop file with `Exec=` rewritten to the absolute `~/.local/bin/anvil` path expanded, `Icon=` to
  the extracted icon path or kept as the icon name with the icon placed in
  `~/.local/share/icons/hicolor/512x512/apps/`), installed tag in
  `~/.local/share/anvil/installed-version`. Run `update-desktop-database ~/.local/share/applications`
  only if present. Warn when `/usr/bin/anvil` also exists.
- **Windows:** `-Stable`, `-Check`, `-AppImage` does not exist there, positional `-Tag`,
  `-AllUsers` (`/ALLUSERS`; needs an elevated shell, say so if not elevated), `-InstallDir`
  (`/DIR="…"`), `-Help`. Run the installer with `Start-Process -Wait -PassThru` and report
  `ExitCode`; non-zero exit is a failure. `[Net.ServicePointManager]::SecurityProtocol` gets TLS 1.2
  added on 5.1. Download with `Invoke-WebRequest -UseBasicParsing`, `$ProgressPreference =
  'SilentlyContinue'` during it (5.1 is very slow otherwise), verify with `Get-FileHash`.
- **One-liners** for the README (Install section, near the top, before the Flutter section):
  - `curl -fsSL https://raw.githubusercontent.com/tkforgeworks/anvil/main/scripts/install/install-anvil.sh | bash` (newest incl. RCs), with `-s -- --stable` / `-s -- v0.2.0` variants.
  - `& ([scriptblock]::Create((irm https://raw.githubusercontent.com/tkforgeworks/anvil/main/scripts/install/install-anvil.ps1))) -Stable`
  - The manual path (Releases page, which asset to pick per platform).
  - A note that the URLs serve from `main`, so they work once 0.2.0 has shipped; until then use the
    script from a checkout of `v0.2.0/main`.
  The scripts must work when piped (`bash` reading stdin; `$PSCommandPath` empty), so no reliance on
  the script's own path.

## Acceptance criteria (ANVL-143, verbatim intent)
Common: locations above; release selection (default newest incl. prereleases, `--stable`, positional
tag, `--check` prints resolved and installed and exits 0, drafts never chosen); public REST, no auth,
no `gh`; download verified against `digest`, mismatch aborts, missing digest warns; up-to-date exit 0;
no-downgrade rule above; clear non-zero failure for a tag without a host asset (every 0.1.x tag);
temp files removed on exit; `--help`.
Linux: deb via apt / rpm via dnf / else AppImage, `--appimage` forces; version compare as above, 0.1.x
counts as older; AppImage install as above; sudo once with keep-alive on deb/rpm paths only; bash
`set -euo pipefail`; needs only curl, sha256sum, python3, the package manager; shellcheck clean.
Windows: silent Inno install as above, version from the `_is1` key (HKCU then HKLM), 0.1.x reported
as older, waits and reports exit code, running-app behaviour documented, works on 5.1 and 7 with
`Set-StrictMode -Version Latest` and `$ErrorActionPreference = 'Stop'`.
