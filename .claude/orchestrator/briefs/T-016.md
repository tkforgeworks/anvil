## Expected outcome
- **`main()`**: `WidgetsFlutterBinding.ensureInitialized()`; `registerForgeFontLicenses()`;
  resolve `getApplicationSupportDirectory()`; construct `AppLogger(directory: <support>/logs,
  minimumLevel: kReleaseMode ? info : debug)` and `AppSettingsStore(filePath:
  <support>/app-settings.json)`; read settings ONCE before the first frame; install the error
  hooks; log `Anvil <version> starting` (version from `pubspec.yaml` is not available at runtime
  without a package; log `Anvil starting` plus the support directory through `anonymizePath`
  if the core exports it, else the raw path); `runApp(ProviderScope(overrides: rootOverrides(...),
  child: const AnvilApp()))`, all inside `runZonedGuarded` whose handler logs through the same
  logger. Put the hook installation in `installErrorHooks(AppLogger logger)`: sets
  `FlutterError.onError` (log `error` with `details.exceptionAsString()` and the stack, then
  forward to `FlutterError.presentError` in debug) and `PlatformDispatcher.instance.onError`
  (log, return true). Each unhandled error produces exactly one `ERROR` line.
- **Providers (`lib/app/providers.dart`)**: `appSupportDirectoryProvider` (`Provider<Directory>`,
  throws `UnimplementedError` until overridden), `appLoggerProvider`, `appSettingsStoreProvider`,
  `appSettingsProvider` (a `Notifier<AppSettings>`, see below), `projectServiceProvider`
  (`ProjectService(supportDirectory: ...)`), `projectSessionProvider` (`Notifier<ProjectSession?>`
  holding null until S2 opens one; only `set`/`clear` for now). A `List<Override>
  rootOverrides({required Directory supportDirectory, required AppLogger logger, required
  AppSettingsStore store, required AppSettings initial})` builds the root overrides so tests can
  call it with a temp directory. Follow §8.1: no codegen; tests use `ProviderContainer.test` or
  `ProviderScope` with `retry: (_, _) => null`.
- **`AppSettingsNotifier extends Notifier<AppSettings>`**: `build()` returns the initial
  settings (read in `main()`, passed through the override); methods `setTheme(AppThemeMode)`,
  `setCustomThemeFile(String path)` (parse with `parseCustomThemeFile`; on success write
  `theme: custom`, `customThemePath`, `customThemeColors`; on failure keep state and expose the
  message through a separate `customThemeErrorProvider` or a small state record, as
  `ThemeSelection.customError` did), `setEditingMode`, `setDefaultSaveLocation(String?)`; every
  mutation goes through `store.update(...)` and then sets `state` from what the store returns, so
  the file is the source of truth. Each change logs one `info` line (0.1.6 logged app settings
  changes).
- **Theme**: `AnvilApp` is a `ConsumerWidget`: `themeDataProvider` maps `AppSettings` →
  `AnvilThemeSpec` (dark/light; custom with `customThemeColors` → `AnvilThemeSpec.custom`, custom
  without colours → dark, exactly as `ThemeSelection.spec` does today) → `anvilTheme(spec)`.
  `MaterialApp(title: 'Anvil', theme: ..., home: PlaceholderHomePage())`. The placeholder home is
  a minimal page (app name, a sentence saying the shell lands with ANVL-184/185, a theme-mode
  `SegmentedButton` driving `setTheme`, and in `kDebugMode` only a button opening
  `ThemeGalleryPage`). Theme colours only through `context.colors`/`context.forge`/
  `context.anvil`: `test/theme/no_hardcoded_colors_test.dart` must pass.
- **`AppLifecycleListener`** in `AnvilApp`'s state (or a small `AppExitHandler` widget):
  `onExitRequested` logs `Anvil shutting down` and returns `AppExitResponse.exit`; S5 will add
  the dirty-editor prompt in front of it. Also log `shutdown` from `onDetach` if the platform
  reaches it.
- **Linux runner**: in `my_application_activate`, after `gtk_window_set_default_size`, set
  geometry hints with `GdkGeometry{min_width = 1400, min_height = 600}` and
  `gtk_window_set_geometry_hints(window, NULL, &geometry, GDK_HINT_MIN_SIZE)`; connect
  `delete-event` on the window to a handler that calls `fl_engine_request_app_exit(engine)`
  (the `FlEngine` from `fl_view_get_engine(view)`) and returns TRUE, so the framework decides
  (this is how `AppLifecycleListener.onExitRequested` is reached on Linux). Keep the header-bar
